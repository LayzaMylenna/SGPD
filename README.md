# Sistema de Gestão de Processos Digitais (SGPD)

##  Objetivo do Projeto

O Sistema de Gestão de Processos Digitais (SGPD) foi desenvolvido como um projeto acadêmico durante a graduação em Engenharia de Software.

O objetivo do projeto é propor uma solução digital para organizar e gerenciar processos, facilitando o acompanhamento das atividades e a organização das informações.

##  Tecnologias e Conceitos Utilizados

- Python
- UML
- BPMN
- Casos de uso
- Modelagem de sistemas
- Prototipação
- Lógica de programação

##  O que foi aprendido

Durante o desenvolvimento do projeto, foi possível aplicar conhecimentos de Engenharia de Software na prática.

A experiência contribuiu para o desenvolvimento de conhecimentos em análise de requisitos, modelagem de sistemas, organização de processos e criação de casos de uso.

Também foi possível aprimorar a utilização de UML e BPMN, além de desenvolver o raciocínio lógico e a capacidade de analisar problemas e estruturar soluções.

##  Desenvolvimento

Este projeto foi desenvolvido como parte da formação acadêmica em Engenharia de Software, com o objetivo de aplicar conhecimentos teóricos em uma situação prática.
